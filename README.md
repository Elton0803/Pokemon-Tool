# Pokémon GO 攻守數據｜寶可夢計算器

這是一個用 Python 和 Streamlit 製作的 Pokémon GO 對戰資料查詢工具。寶可夢計算器會依照對手的屬性、招式屬性與適用的天氣加成，估算極巨對戰的輸出、坦度或團體戰的 DPS，方便挑選打手與坦克。

## 功能

| 分頁 | 操作方式 | 顯示結果 |
| --- | --- | --- |
| 極巨攻擊 | 選擇對手的一至兩種屬性。 | 比較極巨與超極巨招式的估算輸出，並顯示相對於榜首的強度百分比。 |
| 極巨防禦 | 選擇對手的**攻擊屬性**，需要時勾選「開三盾」。 | 依工作簿的防禦數值及承受的屬性倍率計算坦度排行。 |
| DPS計算 | 選擇對手的一至兩種屬性。 | 以基礎 DPS（每秒傷害）乘上屬性倍率和天氣加成，依結果排序。 |
| 屬性克制 | 查看屬性表，或在「屬性弱點計算器」選擇防守方的一至兩種屬性。 | 列出各攻擊屬性的倍率，由高到低排序。 |
| 團體戰輸出查詢 | 在下拉選單搜尋並選取對手寶可夢。 | 自動帶入對手屬性，依估算 DPS 列出前 50 名打手。 |

對手只有一種屬性時，第二屬性選「無」。右上角的「天氣加成」預設為「無」。選擇天氣後，符合該天氣的攻擊屬性會在極巨攻擊、DPS 計算、屬性弱點計算器及團體戰排行套用 1.2 倍加成。

## 在電腦上執行

先安裝 Python 3 和 Git，接著在終端機執行：

```bash
git clone https://github.com/Elton0803/Pokemon-Tool.git
cd Pokemon-Tool
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

開啟終端機顯示的 Local URL（通常是 `http://localhost:8501`），即可切換分頁使用。第一次可以到「團體戰輸出查詢」選取「噴火龍」，查看程式帶入的火／飛行屬性和打手排行。

[chart.png](chart.png) 是「屬性克制」分頁顯示的圖表。更新 Excel 資料後，請保留檔名、欄位名稱及屬性倍率表的位置，再重新執行程式。
